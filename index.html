    NETD manual¶

    NETD is open-source software for a national aggregator of electronic theses and dissertations (ETDs): it harvests thesis metadata from university repositories, cleans and completes it, and offers one search portal, an OAI-PMH data provider and a REST API over the whole collection. It runs the Zambia National ETD Portal at https://netd.ac.zm/, and is written so that another country can install it and adapt it.

    This manual describes the software in general. The Zambian installation's own runbook (its server, schedules, accounts and history) is docs/OPERATIONS.md; the requirements and design are in docs/SRS.md and docs/SDD.md.

    The structure follows the DSpace documentation (Introduction, Release Notes, Installing, Upgrading, Using, System Administration, Configuration, Customisation, Architecture, Interfaces, Development), so that repository managers who know DSpace find things where they expect them.

    Status of this manual (November 5, 2026). The software was built for one country first. The installation's identity (country, portal name and host, regulator, contacts, credits, time zone) is now read from one file, config/country.yml (chapter 7.1); the interface wording is in a locale file (chapter 8.6) and the colours and logos in a theme folder (chapter 8.3); the deployment files still carry Zambian details, and docs/PACKAGING-PLAN.md moves them release by release. The requirements and design documents are under Reference (SRS, SDD).
